# 活动背景与目的

## 活动背景

为丰富校园文化生活，拓展学生社团线上交流与展示形式，充分发挥数字技术在校园文化传播中的作用，
七个学生社团拟联合开展校园联谊二课活动《方块嘉年华》。

活动依托山商MC煤炭社“元山商”校园还原工程搭建线上虚拟校园场景，由电脑技术协会提供活动官方平台和技术支持，
将社团风采展示、互动体验、摄影打卡与校园文化传播融入 Minecraft 场景，为同学们提供安全、有序、富有趣味性的线上社团联谊体验。

## 活动目的

本次活动旨在通过虚拟校园场景集中展示学生社团特色，增进不同社团与在校学生之间的了解和交流；

引导参与者在完成客户端下载、服务器连接、场景探索和图片上传的过程中提升数字工具使用能力；

以线上拍照打卡的方式记录校园文化创意，遴选优秀作品用于下一年度百团大战明信片设计，
进一步增强学生对校园文化和社团文化的认同感。

:::tip[一句话概括]
让七个社团在同一张 Minecraft 地图里被看见，也让参与者在方块校园里留下自己的打卡作品。
:::
