# 奖项设置

本活动为**校园联谊二课活动**，完成报名、服务器打卡并成功上传有效打卡图片的参与者可获得第二课堂分值。

| 项目 | 数值 |
| --- | --- |
| 第二课堂分值 | **0.1 分** |
| 名额 | 700 人 |

:::warning[以有效打卡为准]
分值的认定以「有效打卡 + 在规定时间内上传合格图片 + 通过审核」为准，
具体认定结果由各承办社团依据活动记录共同确认。
:::
