# 活动涉及单位

本次活动由七个学生社团联合开展，分为主办、承办、协办三类角色。

| 角色 | 社团 | 主要职责 |
| --- | --- | --- |
| **主办单位** | [山商MC煤炭社](/docs/clubs/mc-coal) | 活动服务器搭建、元山商校园还原工程场景部署、客户端整合与联机测试 |
| **承办单位** | [电脑技术协会](/docs/clubs/computer-tech) | 搭建并运营活动官方平台，负责报名、客户端领取、打卡上传与平台审核 |
| **承办单位** | [X动漫联盟协会](/docs/clubs/x-anime) | 设计服务器内展示区域与互动项目 |
| **协办单位** | [516轮滑协会](/docs/clubs/skate-516) | 参与展示区域与互动项目设计，共同开展活动宣传 |
| **协办单位** | [摄影协会](/docs/clubs/photography) | 参与展示区域设计，参与优秀打卡图片遴选 |
| **协办单位** | [轩辕文学社](/docs/clubs/xuanyuan-literature) | 参与展示区域与互动项目设计，共同开展活动宣传 |
| **协办单位** | [魔术社](/docs/clubs/magic) | 参与展示区域与互动项目设计，共同开展活动宣传 |

## 分工协作

- **平台侧**：电脑技术协会搭建活动官方平台，设置报名信息填写、客户端压缩包领取、活动说明查看及打卡图片上传功能。
- **服务器侧**：山商MC煤炭社完成服务器搭建、场景部署、客户端整合与联机测试，明确服务器地址、开放时间、连接方法和基础行为规范。
- **内容侧**：各承办社团结合自身特色设计服务器内展示区域和互动项目，提前完成内容审核、场景布置、任务说明及打卡点设置。
- **宣传与保障**：电脑技术协会制作客户端下载安装与服务器连接教程，各社团共同开展活动宣传，建立工作联络机制，
  安排平台审核、服务器维护、答疑和应急处置人员。
