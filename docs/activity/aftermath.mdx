# 活动后期工作

## 数据汇总与认定

电脑技术协会汇总报名及图片上传数据，山商MC煤炭社核验服务器参与记录，各社团共同完成**有效打卡认定和优秀图片评选**。

## 作品版权与个人信息确认

对采纳作品进行版权及个人信息确认，在取得提交者同意后用于下一年度百团大战明信片设计、制作和发放；
**未经同意不对外公开使用**。

## 活动总结与复盘

整理活动过程材料、服务器运行记录、平台数据及优秀作品，形成活动总结，并对**平台操作、服务器稳定性和活动项目设置**进行复盘。

## 个人信息保护

活动结束后按学校要求妥善保管或删除报名信息，关闭不再使用的平台入口和服务器服务，做好个人信息保护工作。

:::danger[关于隐私]
报名信息与打卡图片仅用于本次活动与明信片采纳，未经本人同意不会对外公开使用。
:::
