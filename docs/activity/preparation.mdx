# 活动前期准备

## 平台准备（电脑技术协会）

搭建并测试活动官方平台，设置报名信息填写、客户端压缩包领取、活动说明查看及打卡图片上传功能。

报名信息包括**游戏ID、班级、姓名、联系方式和性别**，并由专人按照活动需要规范管理。

## 服务器与场景准备（山商MC煤炭社）

完成服务器搭建、元山商校园还原工程场景部署、客户端整合与联机测试，明确**服务器地址、开放时间、
连接方法和基础行为规范**。

## 展示内容准备（各承办社团）

各承办社团结合自身特色设计服务器内展示区域和互动项目，提前完成**内容审核、场景布置、任务说明及打卡点设置**。

## 宣传与保障

电脑技术协会制作客户端下载安装与服务器连接教程，各社团共同开展活动宣传，建立工作联络机制，
安排**平台审核、服务器维护、答疑和应急处置人员**。

## 规则制定

制定图片打卡有效性标准和优秀作品采纳规则，明确图片须为参与者**本人在活动服务器内完成相关项目后的游戏截图**，
不得冒用、盗用或提交与活动无关的材料。

:::danger[打卡图片的硬性要求]
必须是本人在活动服务器内完成相关项目后的**游戏截图**。冒用、盗用或与活动无关的材料一律无效。
:::
