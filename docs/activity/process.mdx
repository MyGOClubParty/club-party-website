# 活动流程

## 参与者流程

### 1. 报名

在规定时间内进入电脑技术协会搭建的活动官方平台，如实填写 **游戏ID、班级、姓名、联系方式和性别**等信息，完成活动报名。

### 2. 领取并运行客户端

报名完成后，通过活动官方平台领取活动客户端压缩包，按照教程在规定时间内完成**下载、解压和运行**，
并连接至山商MC煤炭社搭建的活动服务器。

### 3. 完成社团展示小活动

进入以“元山商”校园还原工程为主体的服务器场景，**自主选择并完成至少一项**社团风采展示小活动。

### 4. 拍照打卡

在所选活动区域按要求完成互动并拍照打卡，图片应清晰呈现**本人游戏角色、活动场景及对应社团展示内容**。

### 5. 上传打卡图片

返回电脑技术协会活动官方平台，在规定时间内上传打卡图片。工作人员依据**报名信息、游戏ID、图片内容和服务器记录**进行审核。

### 6. 优秀作品遴选

活动结束后，各承办社团共同遴选构图完整、内容积极、能够体现校园与社团特色的优秀打卡图片。
经采纳的图片拟用于下一年度百团大战明信片制作，并为被采纳作品的提交者专门定制、发放相应明信片。
