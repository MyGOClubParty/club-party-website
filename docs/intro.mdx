# 方块嘉年华 · 活动总览

> 七个学生社团联合开展的校园联谊二课活动，依托山商MC煤炭社“元山商”校园还原工程，
> 把社团风采展示、互动体验、摄影打卡与校园文化传播放进同一张 Minecraft 地图。

## 活动名片

| 项目 | 内容 |
| --- | --- |
| 活动名称 | 山商MC煤炭社2026年第一期“方块嘉年华”校园联谊 |
| 主办单位 | 山商MC煤炭社 |
| 承办单位 | 电脑技术协会、X动漫联盟协会 |
| 协办单位 | 516轮滑协会、摄影协会、轩辕文学社、魔术社 |
| 参与人员 | 山东工商学院全体在校生 |
| 活动地点 | 线上开展（电脑技术协会活动官方平台及山商MC煤炭社 Minecraft 活动服务器） |
| 报名及客户端下载 | 10月17日 8:00 —— 10月19日 15:00 |
| 服务器开放及打卡 | 10月19日 18:00 —— 10月25日 21:00 |
| 作品审核及明信片采纳 | 10月25日 |

## 一句话流程

报名 → 领取客户端 → 连接活动服务器 → 进入“元山商”虚拟校园 → 完成至少一项社团展示小活动并拍照打卡 → 在官方平台上传打卡图片。
